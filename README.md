# Novus Ordo Mundi — De Vijfvoudige Spiegel

Een interactieve puzzel in het Fluisterwoud voor vijf helden, behorend bij de campagne **Novus Ordo Mundi**.

## Spelen

- Open de gepubliceerde website op het grote scherm om de vijf runen te plaatsen.
- Iedere held krijgt een persoonlijke aanwijzing via een rol-URL: `?rol=quasar`, `?rol=gnarly`, `?rol=kagen`, `?rol=bryndis` of `?rol=vespera`.
- Voor de DM bestaat `?dm=1`, met een bedienpaneel voor hints en de juiste volgorde.
- DM-paneel en spelersscherm synchroniseren **alleen op dezelfde browsercomputer / origin**, niet tussen telefoons.

## GitHub Pages

Ga naar **Settings → Pages** en kies **Deploy from a branch**, **main** en **/(root)**. De verwachte project-URL is:

https://fathom-web.github.io/D-D-Puzzle-I/

Gebruik `index.html` in de repositoryroot. De echte URL werkt pas nadat Pages is ingeschakeld en de publicatie voltooid is.

## Canon

Dit is een optioneel **VOORSTEL** binnen Chapter 1, geen vastgestelde canon. De spiegelende waterkring is **niet** de demonische spiegel uit de Holte van de Vergetenen.

## Belangrijke opmerking voor de DM

Deze site is volledig statisch en publiek. Antwoorden en hints zijn via broncodeonderzoek te vinden; `?dm=1` is geen beveiligd beheerdersaccount. Publiceer nooit vertrouwelijke spelergegevens of andere echte geheimen in deze repository. De afzonderlijke, uitgebreidere DM-handleiding blijft buiten de publieke repository.
